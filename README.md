## 📱 Descripción

Aplicación Android desarrollada en **Java** que permite consultar personajes de Dragon Ball mediante una API REST.

El usuario puede ingresar el ID del personaje y obtener:

✨ Nombre  
⚡ Nivel de Ki  
🧬 Raza  
👤 Género  
🖼️ Imagen  
🔥 Transformaciones


---

## 🚀 Funcionalidades

| Función | Descripción |
|---|---|
| 🔎 Buscar personaje | Consulta información usando el ID |
| 🖼️ Imagen | Carga la imagen automáticamente |
| 🔥 Transformaciones | Muestra las formas disponibles |
| 🔄 Reiniciar | Limpia la búsqueda |


---

## ⚠️ Manejo de errores

La aplicación controla diferentes situaciones durante la búsqueda:

✅ Validación de ID vacío  
✅ Mensaje cuando el personaje no existe  
✅ Limpieza automática de la información mostrada  
✅ Control de personajes sin transformaciones  
✅ Manejo de respuestas de la API REST
